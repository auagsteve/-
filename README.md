## 开发环境及前置要求

Arduino Uno 是一种使用方便且完全开源的开发平台，其编程语言基于 C/C++，上手相对简单。相比 STM32，Arduino 编程更为直观便捷，因此本项目选择 Arduino 平台作为开发基础。

### 前置要求

1. **Arduino IDE**  
   下载地址：[https://www.arduino.cc/en/software/](https://www.arduino.cc/en/software/)  
   请根据你的操作系统选择对应版本进行安装。

2. **开发板软件包**  
   Arduino Uno 的核心库通常已内置。若使用其他开发板，请进入菜单：  
   `工具 -> 开发板 -> 开发板管理器`，搜索并安装对应型号的支持包。

3. **串口驱动程序**  
   我的 USB 转串口驱动早已安装。首次使用者可在 Arduino IDE 安装目录下的 `drivers` 文件夹中查找适合的驱动程序并手动安装（常见为 CH340 或 ATmega16U2 驱动）。

4. **所需传感器与舵机扩展库**
   - 本项目使用 PWM 控制 SG90 舵机，并通过 I2C 通信读取 MPU6050 数据。
   - 需要在 Arduino IDE 的库管理器中安装：
     - `Adafruit MPU6050`
     - `Adafruit Unified Sensor`（依赖项）
   - 安装方式：`工具 -> 管理库 -> 搜索 "Adafruit MPU6050"` → 安装。

## 程序介绍

本项目采用 **一阶低通滤波算法** 对 MPU6050 获取的姿态数据进行处理，有效抑制传感器噪声，显著改善舵机运动过程中的抖动问题，尤其是在转动到极限位置时的“抽动”现象。

此外，MPU6050 存在固有的零偏误差（Zero-Offset），建议在烧录主程序前先对三轴加速度进行标定。
